# CoffeeQR — plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App CoffeeQR (Office): QR llamativos y legibles, sin internet, con descarga PNG/SVG/PDF y hoja de stickers.

**Architecture:** Lógica pura en `CoffeeQR/src/qr/` (contenido → texto, matriz con qrcode-generator, SVG con formas/ojos/degradado/adornos/marco, contraste, PDF con pdf-lib), probada en Node rasterizando con resvg y leyendo con jsQR. La interfaz React usa `useStudioDoc` (un documento `.cqr`).

**Tech Stack:** Tauri 2, React 19, Vite 6, Tailwind; qrcode-generator 2.0.4 (MIT), jsqr 1.4.0 (Apache-2.0), pdf-lib (MIT); @resvg/resvg-js (pruebas).

**Spec:** `docs/superpowers/specs/2026-11-28-coffeeqr-design.md`

## Global Constraints

- Puerto 1445, categoría Office, color `#5f3dc4`, extensión `.cqr`, versión 2.18.0.
- Todo sin internet; textos en español; dibujos de adornos originales.
- Ningún diseño se descarga sin pasar por el semáforo (rojo = aviso claro antes de descargar).

## Review Focus

- Colores invertidos (QR claro sobre fondo oscuro): muchos lectores fallan → semáforo amarillo/rojo con explicación (prueba en Task 4).
- Contenido muy largo (> capacidad con corrección H): error claro y sugerencia de acortar (Task 2).
- Logo grande en el centro: no debe pasar del ~15 % del área; se limita (Task 3).
- Fondo transparente + módulos claros: el PNG sin fondo puede no leerse sobre papel blanco; avisar (Task 4).
- Wi-Fi con `;`, `,`, `:` o `\` en la clave: deben escaparse (Task 2).

### Task 1: Estructura de la app
- Copiar CoffeeLatex como base (sin `foto/`, `preview/`, `editor/`, `exportar/`), renombrar a `coffeeqr`/`CoffeeQR`, puerto 1445, `editor_handler!()`; deps `qrcode-generator`, `jsqr`, `pdf-lib`; dev `@resvg/resvg-js`, `tsx`.
- Workspace Cargo, `sync-shared` (theme, studio), `make-theme` (`CoffeeQR: "light"`).
- [ ] `npm run build` y `cargo check -p coffeeqr`; commit.

### Task 2: Contenido (`src/qr/contenido.ts`)
- `type Contenido = { tipo: "enlace"|"archivo"|"texto"|"wifi"|"contacto"|"whatsapp"|"correo"|"telefono"|"sms"|"ubicacion"; ... }`
- `aTexto(c: Contenido): string`; `esDrive(url): boolean` y `consejoEnlace(url): string | null`.
- [ ] Pruebas: Wi-Fi escapa `\ ; , : "` (`WIFI:T:WPA;S:Mi\;Red;P:a\:b;;`), sin clave `T:nopass`; vCard 3.0 con nombre, teléfono, correo, empresa, web; WhatsApp limpia el número (`wa.me/573001234567?text=Hola%20mundo`); correo `mailto:` con asunto/cuerpo codificados; ubicación `https://maps.google.com/?q=4.6,-74.08`; enlace sin esquema recibe `https://`; enlace de Drive reconocido.

### Task 3: Matriz y dibujo (`src/qr/matriz.ts`, `src/qr/dibujo.ts`)
- `matriz(texto: string, nivel?: "L"|"M"|"Q"|"H"): { n: number; oscuro(f,c): boolean; esOjo(f,c): boolean }`; lanza `Error("El contenido es demasiado largo para un QR")`.
- `interface Diseno { modulo: Forma; ojoMarco: FormaOjo; ojoCentro: FormaCentro; color: Relleno; colorOjos?: string; fondo: string | null; margen: number; tema: TemaId | null; adornoCentro: boolean; adornoBorde: boolean; logo: string | null; marco: { texto: string; color: string; estilo: "abajo"|"burbuja"|"ninguno" } }`
- `dibujarSvg(texto: string, d: Diseno): { svg: string; ancho: number; alto: number }`.
- [ ] Pruebas: cada `Forma` (9) × 3 ojos × sólido/degradado, cada tema con adorno en el centro y en el borde, logo del 15 %, y marco: rasterizar con resvg a 600 px y leer con jsQR ⇒ texto exacto. Contenido de 3000 caracteres ⇒ error.

### Task 4: Adornos, plantillas y lectura
- `src/qr/adornos.ts`: `TEMAS` (9) con `insignia` y `borde` en SVG original.
- `src/qr/plantillas.ts`: `PLANTILLAS` por negocio (diseño + texto del marco + tipo de contenido sugerido).
- `src/qr/lectura.ts`: `contraste(a, b): number` (WCAG); `evaluar(lecturas: {grande: boolean; chico: boolean}, d: Diseno): { nivel: "verde"|"amarillo"|"rojo"; motivos: string[] }`.
- [ ] Pruebas: negro/blanco contraste 21; módulos claros sobre fondo oscuro ⇒ motivo «colores invertidos»; contraste < 3 ⇒ rojo; sin fondo + módulos claros ⇒ aviso; cada plantilla se lee.

### Task 5: Exportar (`src/qr/exportar.ts`)
- `pdfQr(png: Uint8Array, cm: number): Promise<Uint8Array>` y `hojaStickers(png, cm, margenMm): Promise<Uint8Array>` (A4, cuántos caben), `cabenEnA4(cm, margenMm): { columnas; filas }`.
- [ ] Pruebas: PDF empieza por `%PDF`, 1 página; 4 cm en A4 con 10 mm ⇒ 4×6; hoja de stickers con 24 imágenes dibujadas.

### Task 6: Interfaz
- `App.tsx`: inicio (plantillas, recientes, abrir); editor con panel izquierdo (Contenido · Estilo · Colores · Adornos · Marco), vista grande al centro con semáforo, panel de descarga (PNG con/sin fondo y tamaño, SVG, PDF, hoja de stickers).
- Semáforo: rasteriza en canvas a 600 y 180 px, lee con jsQR, `evaluar`.
- [ ] e2e: plantilla «Tienda de plantas», cambiar forma a puntos y color, semáforo verde, descargar PNG sin fondo (PNG con alfa) y SVG que se lee; contenido Wi-Fi.
