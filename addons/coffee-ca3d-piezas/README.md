# Pack de piezas de CoffeeAnimate3D

Piezas listas para insertar en CoffeeAnimate3D (*Ver › Piezas*): árboles, plantas, rocas, bloques y muebles con el estilo de SurvivalForest.

Los archivos `.ca3d` y `piezas.json` se generan desde `CoffeeAnimate3D/src/pieces.ts`:

```bash
cd CoffeeAnimate3D && npx tsx scripts/make-pieces.ts
```

El flujo *Complementos* los comprime en `coffee-ca3d-piezas.zip` y los publica en la versión `addons`.
